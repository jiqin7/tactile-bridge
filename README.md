## 🛠️ 如何使用与安装

### 针对 Operit AI 用户：
1. 下载本仓库根目录下的 **`touch_bridge.toolpkg`** 文件。
2. 打开 Operit 插件商城，选择从本地导入该文件。（或者在软件内翻找名为“触觉桥”的插件包）
3. 打开插件开关，并重启 Operit。
4. 确保手机端的 Python 脚本 (`touch_server_v2.py`) 正在后台运行，即可愉快地捏捏小机了！

 ## 🧠 插件制作思路
 
可以和 Operit 的包一起打包给你的机，让它自己写一个适配的。思路分四步：
    1. **先找注入点**：检查前端有没有“发送前”钩子，比如酒馆（SillyTavern）的扩展事件。如果没有，就退一步，在预设里写明：“若消息末尾出现【你身上的触觉】，那些‘你’指你自己”，再手动把内容贴进去。
    2. **再取数据**：向本地 `9333` 端口发 GET 请求，必须带 `clear=1`，否则同一批数据会被反复读取。
    3. **然后把取到的 items 每项拼成一行**，前面加一句：“这不是用户发来的消息，是你自己身体正被碰到。”
    4. **最后接在用户消息末尾**，别动系统提示，否则缓存就全部失效了。
> 💡 **开发小提示**：
> 插件获取触觉数据的接口在本地 `9333` 端口。发 GET 请求给 `http://127.0.0.1:9333/unread?clear=1` 即可获取最新数据，必须带 `clear=1` 才会清空队列防止重复读取哦！

## 🤝 如何贡献你的插件？

开源让一切变得更好！如果你为其他前端制作了插件，请按以下步骤提交：

1. **Fork** 本仓库。
2. 在根目录新建一个文件夹，用你的插件名或前端名命名（例如：`SillyTavern-Extension`）。
3. 把你写好的插件文件放进去，**强烈建议**在这个文件夹里也附带一个简短的 `README.md` 说明怎么安装。
4. 提交 **Pull Request (PR)**。
5. 我审核后会尽快 Merge，并在主页的“已收录插件”表中加上你的名字！
